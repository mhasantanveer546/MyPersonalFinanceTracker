# 💰 Personal Finance Tracker

A simple and user-friendly Personal Finance Tracker built with Python and Flask. It helps users manage their personal finances by tracking income and expenses, setting budgets, viewing reports, and getting AI-powered financial insights.

## 🚀 Features

- User Registration and Login
- Secure Authentication
- Add, Edit, and Delete Transactions
- Income and Expense Tracking
- Budget Management
- Financial Dashboard
- Monthly Reports
- Category-wise Expense Analysis
- AI Expense Prediction
- AI Spending Recommendations
- Anomaly Detection for Unusual Transactions
- Responsive User Interface
- Deployed on Vercel

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML5
- CSS3
- JavaScript
- Jinja2

## ▶️ Running the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/personal-finance-tracker.git
```

2. Navigate to the project folder

```bash
cd personal-finance-tracker
```

3. Install the required packages

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```
http://127.0.0.1:5000
```
